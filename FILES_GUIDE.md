## 🔄 Workflow

### Local Development
```bash
1. Create .env from .env.example
2. npm install
3. npm run dev
4. Test locally with @rawshot_bot
5. npm run build
```

### Before Deploying
```bash
1. Edit .env.example with descriptions
2. Add to README.md if needed
3. Test npm run build
4. Create .gitignore entries
5. Commit to GitHub
```

### Deployment
```bash
1. Push to GitHub
2. Vercel auto-deploys
3. Add env variables in Vercel dashboard
4. Test @rawshot_bot on Telegram
```
